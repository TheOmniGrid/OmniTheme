# Security policy

## Supported versions

Security reports should target the most recent OmniTheme build or the current public documentation. Older builds may be evaluated when the same issue still affects the current version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email [omnivex@theomnigrid.biz](mailto:omnivex@theomnigrid.biz) with:

- OmniTheme and the affected version;
- the affected component and platform;
- reproduction steps or a minimal proof of concept;
- expected impact;
- privacy-redacted supporting material.

Do not include credentials, private download links, personal data, or third-party content that you are not authorized to share.

The project will acknowledge the report, attempt to reproduce it, and coordinate disclosure when a fix or clear mitigation is available. There is currently no formal bug-bounty program.
